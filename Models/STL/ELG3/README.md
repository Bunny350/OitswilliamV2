# Note: early access. Expected to be released on early 2027.
## Directory printing guide for ELG3
This page shows what method you should use when choosing. Directories that are not in list must have all parts printed (excluding another directory in it).

### Legend: Parent / Child / Child / [Variants] ...

### Directories that need all parts in it printed:
* Filter cartridge
* Main unit
* LED back (opaque visibilities)
    - These can be found in previous generation's folders until ELG3 official release.
* Bowden coupler with HFS (hybrid filament sensor)
- Reserved parts

### Custom adjustments required for the parts:
* Reserved mesh (elg3_reserved_mesh_X2)
    * No top or bottom shells (must have infill exposed)

### Directories that let you print either part by back panel thickness:

* LED Back / [Back panel thickness (4 / 6mm)]
    - These can be found in previous generation's folders until ELG3 official release.

### Directories that let you print one of either part by whether should you embed a webcam to ELG3:

* Main unit/Webcam
